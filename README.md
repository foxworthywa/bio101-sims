# BIO 101 simulations

Static, single-file browser simulations for BIO 101 (General Biology), hosted with GitHub Pages.

- `push-or-shake.html`: how ATP powers a protein machine (sodium–potassium pump), Chapter 4.

To host: create the repository `bio101-sims`, push these files to `main`, then Settings → Pages → Deploy from branch `main` / root.
The Canvas pages link to `https://foxworthywa.github.io/bio101-sims/push-or-shake.html`.
